# ANIKIRUN

福井県池田町のキャラクター「アニキ」が登場する、シンプルな横スクロールジャンプゲームです。アニキを走らせ、熊を飛び越えて、ゴールを目指しましょう！

![ANIKIRUN ゲームプレイスクリーンショット](http://codeforfukui.github.io/ANIKIRUN/ss.png)

## デモ

ブラウザでゲームをプレイ: **[http://codeforfukui.github.io/ANIKIRUN/](http://codeforfukui.github.io/ANIKIRUN/)**

## 特徴

- **シンプルな操作:** 画面をタップするだけでジャンプできます。
- **無限のステージ:** 障害物を避けながらステージをクリアし、走り続けましょう。
- **スコア記録:** 現在のスコアとハイスコアを記録します。
- **軽量:** PCやモバイルのモダンブラウザで動作します。

## 遊び方

1. [デモページ](http://codeforfukui.github.io/ANIKIRUN/)を開きます。
2. 画面をタップしてゲームを開始します。
3. 再度タップすると、アニキが熊の障害物を飛び越えます。
4. コースの最後にあるゴールに到達すると、次のステージに進みます。
5. アニキが熊に衝突するとゲーム終了です。
