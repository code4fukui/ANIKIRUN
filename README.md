# ANIKIRUN

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple side-scrolling jump game featuring ANIKI, a character from Ikeda, Fukui Prefecture, Japan. Help ANIKI run, jump over bears, and reach the goal!


![ANIKIRUN Gameplay Screenshot](http://codeforfukui.github.io/ANIKIRUN/ss.png)


## Demo

Play the game in your browser: **[http://codeforfukui.github.io/ANIKIRUN/](http://codeforfukui.github.io/ANIKIRUN/)**

## Features

-   **Simple Controls:** Just tap the screen to jump.
-   **Endless Stages:** Avoid obstacles to clear stages and continue running.
-   **Score Tracking:** The game keeps track of your current score and high score.
-   **Lightweight:** Runs in any modern web browser, on desktop or mobile.

## How to Play

1.  Open the [demo page](http://codeforfukui.github.io/ANIKIRUN/).
2.  Tap the screen to start the game.
3.  Tap again to make ANIKI jump over the bear obstacles.
4.  Reach the goal at the end of the path to advance to the next stage.
5.  The game ends if ANIKI collides with a bear.
